Open it

Tab Manager Plus shows all your open windows and tabs in one place, so that you can find, sort and close them quickly. To open it, click its icon in the browser toolbar or press the shortcut below, and then simply start typing to search.

Do thisWhat it is for
AltShiftMCtrlShiftMMacOpens Tab Manager Plus from any page, so you can find a tab without reaching for the mouse.
AltShift,CtrlShift,MacJumps straight back to the tab you used before, which is handy when you keep switching between two pages.
 Right-click the toolbar iconPick "Open in own tab" to use Tab Manager Plus in a full browser tab, which gives you much more room for many windows.
 Right-click the toolbar iconPick "Open sidebar" to keep Tab Manager Plus at the side of the page, so you can see your tabs while you work.

These shortcuts are the ones a new install gets. If you updated from an older version, you keep the keys you already had, and the options show which keys you have right now.

Find a tab

Searching is the fastest way to find one tab among hundreds. As soon as you type a word, the tabs with that word in their title or web address stay bright, while all the other tabs fade into the background. When you type several words, a tab has to contain every one of them to count as a match.

Typing in the search box: tabs that match stay bright and the rest fade.

TypeWhat it finds, and when it helps
reactEvery tab with "react" in its title or address, for example all the pages about a topic you are reading up on.
github issueOnly the tabs that contain both words, which narrows a long list down to the few pages you want.
github OR redditTabs that contain either word, so you can gather two kinds of pages in one search.
t:releaseLooks only at the page titles, which helps when the word also appears in many web addresses.
u:githubLooks only at the web addresses, so you find every page from one site, whatever its title says.
-redditLeaves out every tab with this word, so the rest of the results are easier to look through.
-u:old.redditLeaves out the tabs from one address, even when the word also appears in their titles.
"pull request"The exact phrase with the words side by side, instead of the two words anywhere in the tab.
/localhost:\d+/A pattern instead of a plain word. This one finds the test sites a web developer runs on their own computer.
/\.pdf$/Every tab whose address ends in .pdf, so you can collect all your open documents at once.
/\(\d+\)/Tabs with a number in brackets in the title, like "Inbox (3)", which usually means unread messages.
s:taxLooks only in your saved windows, for example to find the tax pages you put away last month.
s:u:githubLooks at the addresses in your saved windows, so you can find a saved page by its site.
-s:taxLooks only at the tabs that are open right now and ignores your saved windows.
-s:Shows only your open windows and selects nothing, which hides the saved windows for a moment.
  • The search also selects the open tabs it finds, so that you can close or move them in one step. When no open tab matches, it selects the matching tabs in your saved windows instead.
  • When only one tab matches, press Enter to switch to it, which is often faster than looking for it yourself.
  • When several tabs match, Enter moves them all into a new window, so the pages of one topic end up together.
  • Press Esc when you are done, because it clears the search and brings all your tabs back into view.
  • If the faded tabs get in the way, use the ⁠Hide tabs that do not match search button in the bottom bar. After you click it, you see only the matching tabs until you click it again.
  • If you forget these examples, rest the mouse on the small question mark at the right end of the search box for a moment, and a card will list all of them.

Select tabs

Selecting tabs lets you deal with many tabs at once, because the buttons in the bottom bar then work on all the selected tabs together. For example, you can select ten old tabs and close them all with a single click.

Do thisWhat happens
 Click a tabSwitches to that tab in the browser, so you can go straight to the page you were looking for.
 Right-click a tabSelects the tab and leaves you in Tab Manager Plus. A second  right-click takes it out of the selection again.
Ctrl + click⌘ + clickMacAlso selects the tab, which feels natural if you select files on your computer this way.
Shift + right-clickSelects every tab between the last one you picked and this one, which saves many clicks in a long row.
 Middle-click a tabCloses that one tab right away, which is the quickest way to get rid of a single page.

Two buttons in the bottom bar select tabs for you, which helps when you want to tidy up but do not know where to start.

ButtonWhat it is for
Highlight DuplicatesSelects the extra copies when the same page is open more than once, and keeps the copy you used last. One press of the delete keys below then closes only the copies.
Highlight recently active tabsSelects the tabs you used most recently, so you can gather the pages of your current task into their own window.

The clock first looks at the last 15 minutes. If you used fewer than two tabs in that time, it looks further back, to one hour, then 3 hours, 12 hours, a day and so on. Each new click reaches back to the next time span that adds more tabs, and a small mark under the clock lights up for each step. The fourth click turns the clock off again.

Once you have selected some tabs, you can act on all of them at once with the keys and buttons below.

Keys or buttonWhat it does to the selected tabs
CtrlDelor CtrlBackspace⌘⌫MacCloses all the selected tabs at once. If the tabs you selected are in a saved window, they are deleted from that saved window instead.
EnterMoves the selected tabs into a new window of their own, which is a good way to split one project away from the rest. With only one tab selected, it simply switches to that tab.
Move tabs to new windowDoes the same as the Enter key, so you can move the selected tabs into a new window with the mouse.
Close selected tabsCloses every selected tab, which is handy after a search has picked out the pages you no longer need.
Discard selected tabsPuts the selected tabs to sleep so that they use less memory, while they stay where they are. A sleeping tab loads again as soon as you open it, so this helps when your computer feels slow.
Pin selected tabsPins the selected tabs to the left end of their window, where they stay small and are hard to close by mistake. Click it again to unpin them.
Save selected tabsKeeps the selected tabs together as a new saved window, so you can close them now and open them again later.

Here is a quick way to tidy up: search for a word,  right-click one of the results, and then press the delete keys to close all the selected tabs. While you are still typing in the search box, though, the same keys delete a word of your search instead.

Keyboard

You can do almost everything without the mouse, which is faster once you know a few keys. The arrow keys move a ring from tab to tab, but the ring only shows where you are, so moving it does not select anything.

Moving through the tabs with the arrow keys and picking tabs with Space.

KeysWhat they do
←→Move the ring to the tab before or after, so you can walk through a window one tab at a time. In List view, they jump to the window before or after.
↑↓Move the ring to the window above or below. In List view, where each tab has its own line, they move from tab to tab instead.
SpaceSelects the tab under the ring, or takes it out of the selection again, just as a  right-click does.
Shift→Moves the ring and selects every tab it passes, which is a fast way to select a whole row of tabs.
EnterSwitches to the tab under the ring when nothing is selected, so a few arrow presses and Enter take you to any tab.
Ctrl↓or Alt↓Ctrl↓MacLeaves the search box and moves the ring, while the plain arrow keys keep moving inside your search text.
TabMoves the focus from button to button. Then Enter or Space presses the button that has the focus.
EscOne press closes an open hover card and clears the search and the selection. When there is nothing left to clear, another press closes Tab Manager Plus.
CtrlZ⌘ZMacUndoes a mistake: it brings back a saved window or saved tab you have just deleted, as long as its Undo note is still showing.

Windows

Tab Manager Plus gives each window a name made from its sites, like "GitHub, Gmail", so you can tell your windows apart at a glance. You can also give a window your own name and a color, and both stay even after you restart the browser.

Your current window always comes first, and the other windows follow in the order you last used them, with minimized windows at the end. This means that the order changes whenever you switch to another window.

Each window has a row of buttons, which you can hide in the options if you prefer a cleaner look.

ButtonWhat it is for
Save this window for laterKeeps a list of the window's tabs inside Tab Manager Plus, while the window itself stays open. You can close the window afterwards and open it again later with the same tabs, which is ideal for a project you will come back to next week.
Open a new tabOpens an empty tab in this window, which is useful when you want a new page next to the related ones and not in the window you happen to be in.
Change window name or colorLets you give the window a name and a color of your choice, so you can find it quickly later. Clicking the window's name does the same.
Minimize this windowMoves the window out of the way without closing it, so all its tabs stay open. When the window is already minimized, the same button brings it back.
Close this windowCloses the whole window with every tab in it, not just one tab. If you only want to close one tab,  middle-click that tab instead.
  • To move a tab, drag it to a new place, and a marker shows you where it will land when you let go.
  • To move several tabs at once, select them first and then drag one of them, so that they travel together as a small stack.
  • To move a tab to another window, drop it on that window, which is often easier than dragging tabs in the browser itself.
  • If your windows keep growing too long, set "Limit Tabs Per Window" in the options, because then new tabs open in a new window once a window is full.
  • If you never use the window buttons, turn off "Show action buttons" in the options so that your windows look cleaner.

Saved windows

Saving a window keeps a list of its tabs inside Tab Manager Plus. You can then close the window and open it again later, with the same tabs, size and place on screen. Use it for a project you will come back to next week, or for pages you want to read later but do not want open all the time. Saved windows come after your open windows and have a dashed edge, so you can tell them apart.

Saving some tabs as a window, moving them, and getting them back with undo.

Do thisWhat happens
On a windowSaves the whole window with all of its tabs, so you can close it without losing anything.
In the bottom barSaves only the tabs you selected, which is handy when one window holds several topics and you want to keep just one of them.
Restore this saved windowOpens the saved window again with its tabs, in the same size and place as before. A window that was maximized comes back maximized on the same monitor, if that monitor is still connected.
 Click a saved tabOpens just that one page, which is quicker when you need a single tab and not the whole window.
 Click the nameLets you rename the saved window or give it a new color, so that you can find it again among many others.
Delete this saved windowDeletes the saved window when you no longer need it, and an Undo note shows for 8 seconds. While the note shows, the Undo key from the Keyboard part also brings it back.
Drag a saved tabOpens that page in the open window you drop it on, while the saved window keeps its own copy.
Drag an open tabAdds a copy of the tab to the saved window you drop it on, so you can add pages to a saved project.
Drag a saved windowChanges the order of your saved windows when you drag one by its name or edge, so the important ones come first.
s:taxSearches only your saved windows, which helps once you have saved many of them over time.
  • Saved tabs come back without their back and forward history, so the back button in a restored tab has nowhere to go.
  • You can keep a copy of all your saved windows in a backup file that you can store anywhere you like. Click "Export Sessions" in the options to make one, for example before you reinstall your browser.
  • To bring them back, for example on a new computer, click "Import Sessions" and pick that file. Windows that you already have are skipped, so nothing shows up twice.
  • A saved private window opens as a private window again, and private and normal tabs are never mixed in one saved window.
  • In Firefox, importing does not work in the small popup, so open the options page or open Tab Manager Plus in its own tab first.

Layouts and theme

You can choose how your windows are laid out, because some layouts suit a few windows and others suit many tabs. The ⁠layout button at the right end of the bottom bar changes the layout, and each click moves on to the next one.

Switching the layout and the theme with the two buttons.

LayoutWhat you see, and when it suits you
BlockEach window is a card in a grid, with every tab as a small icon. It fits a lot on the screen when you know your sites by their icons.
Big BlockThe same grid with bigger cards and icons, which is easier to read and easier to click.
RowsEach window is one long row, which works well when you have a few windows with many tabs each.
ListOne tab per line with its full title, so you can read what each tab is. Four small bars on the right show when you last used it, green for the last few minutes.
  • The ⁠theme button at the top switches between System, Light and Dark, and System simply follows the dark mode of your computer.
  • If you want to see more at once, turn on "Compact mode" in the options, which makes everything a little tighter.
  • If moving things distract you, turn off "Animations" in the options, and Tab Manager Plus will change without any motion.
  • If you need more room,  right-click the toolbar icon and pick "Open in own tab", and the options can make this the normal way to open it.
  • In Firefox, you can  right-click the toolbar icon and pick "Open sidebar" to keep Tab Manager Plus next to your page while you browse.

Hover cards

When you rest the mouse on something for a moment, a small card appears and tells you more about it. This helps you decide which tabs to close without opening each one of them first.

Resting the mouse on a tab, a window and a button shows a small card.

Rest onThe card shows
A tabWhen you last used it, and whether it is asleep, muted or pinned. It also shows which tab opened it and where its copies are, which helps you decide if you still need it.
A windowIts tabs, its sites and its size, with a small map of where the window sits on your monitors, so you can find it on the screen.
A saved windowWhen you saved it, and a map of where it will open, so you know what to expect before you restore it.
A buttonWhat the button does, and the key that does the same thing if there is one, so you learn the shortcuts as you go.

In Chrome, turn on "Show all monitors" in the options if you use more than one screen, so that the map shows every monitor. The switch asks the browser for the monitor permission. Chrome usually grants it without asking you anything.

Options worth knowing

Click the ⁠Options button at the top to open the settings. Most people never need to change anything there, but these settings are worth knowing about.

The options screen: the settings backup and the list of keys.

  • Popup size makes Tab Manager Plus larger or smaller, up to 800 by 600, because the browser does not allow anything bigger. If you need more room than that, open it in its own tab.
  • Count Tabs shows the number of open tabs on the toolbar icon, which reminds you when it is time to tidy up.
  • Donate and Rate buttons lets you hide those two buttons at the top if you do not want to see them, while the theme button stays where it is.
  • Settings backup saves your settings in a backup file that you can keep anywhere. You can load it in another browser or on a new computer, so that you do not have to set everything up again.
  • Export tabs for debugging makes a file with your windows, tabs, saved windows and settings that you can attach to a bug report. Nothing is sent anywhere unless you send the file yourself.
  • Allow in Incognito lets Tab Manager Plus show your incognito tabs too, and its link opens the Chrome page where you can turn this on.
  • Allow in Private Windows lets Tab Manager Plus show your private tabs too. To turn it on, open about:addons, click Tab Manager Plus and set "Run in Private Windows" to Allow.
  • Shortcut keys lists the keys you have now, and the Change shortcut keys button at the bottom (where your browser allows it) lets you change them. When a line says "Not set", that action has no key yet, and you can give it one.

Questions people ask

Can I see tab groups?

Not yet, because Tab Manager Plus does not show tab groups today. The tabs in a group still appear, just like any other tab in their window.

Why do the windows jump around?

The list puts the window you used last at the top, so the order changes every time you switch windows. Your current window is always first, which means the window you are working in is always easy to find.

I can't see all my tabs.

Try the List view, make the popup bigger in the options, or open Tab Manager Plus in its own tab, because all three give you more room. Also check the ⁠Hide tabs that do not match search button in the bottom bar. While it is turned on, it hides every tab that does not match your search.

Did the X close my whole window?

Yes, it did. The ⁠Close this window button (the red X) closes the whole window with all its tabs at once. To get the window back, open your browser's history, or press Ctrl+Shift+T (Cmd+Shift+T on a Mac) to reopen what you closed last.

Does my data leave my browser?

No, because there is no tracking of any kind. Your settings and saved windows stay inside your own browser and are never sent anywhere. You can read the details in the privacy policy.

Chrome or Firefox?

Both browsers work the same way, apart from a few small differences, and this page only shows the lines that apply to your browser.

  • In Firefox, you also get the sidebar and the steps for turning on private windows.
  • In Chrome, you also get the "Show all monitors" switch, which lets the window map show every screen.

Something is broken. Where do I tell you?

Please open an issue on GitHub and describe what happened. A debug file from the options helps a lot, because it shows how your windows and tabs looked at the time. The file holds open tab addresses without the part after a ? or #, saved windows whole so the file can restore them, and titles as they are. Look it over before you share it.
