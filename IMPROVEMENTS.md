## P0 — Next release (7.0.1) shortlist

The items below are the ones worth doing first. Each points at its full entry further down.

1. Window identity hash can transplant a name or color onto the wrong window after a restart — 1.15 (also raised by Copilot on #273).
2. Importing a saved-windows file replaces a stored window with the same id without a notice or Undo — P1b #2.
3. Public suffix list drops bare wildcard rules, so sites under seven ccTLDs are named "COM" — P1b #3.
4. A foreign drag (link, image, text) moves the current selection — P1b #7.
5. A rejected `storage.local.set` from an option handler shows no notice — P1b #18.
6. Focus falls to the page body when a focused notice unmounts — P1b #26.
7. Freshness label ("just used") goes stale in own-tab and sidebar modes — P6.1.
8. Drops of our own drag type on the search box type text into it (Firefox harness) — P6.2.
9. Cross-page drops onto a saved window do nothing — P6.3.
10. Move `system.display` to required permissions and default "Show all monitors" to on — P6.7.
11. Popup `sendMessage` calls without a catch log "Receiving end does not exist" — 1.6.

Left as they are unless someone sees them: P1b #1, #10, #11, #19 (maintainer decisions on publish day).

## P1b — Findings of the review of PR #273 (2026-10-09/10)

**7.0.0 status: ✅ 18 of 28 fixed before the merge · ⬜ 5 open · 🚫 4 left by decision · 1 regression found and reverted (#24).**

A cloud review of `master...7_0_0` (9 area reviewers, 3 verifiers, two passes) produced 28 findings: 0 blocker, 4 high, 5 medium, 19 low. Full text with failure scenarios and fixes: `REVIEW-7_0_0.md` on the branch `review-7_0_0-findings`. Numbers are the review's. 18 were fixed before the merge; what follows is the rest, in the maintainer's order of value.

Open, planned for 7.0.1:

- ⬜ **#2 high**: importing a saved-windows file replaces a stored saved window with the same id without a notice or Undo (`src/popup/sessionStore.ts:91`; `TabOptions.tsx` dedups only on equal tab urls, `importCount.ts`). Rule: skip when the stored one is newer, say "kept yours" in the notice, offer Undo.
- ⬜ **#3 high**: `scripts/psl.mjs:69` drops bare wildcard rules (`*.np`, `*.jm`, `*.mm`, `*.pg`, `*.ck`, `*.er`, `*.fk`), so sites there are named "COM" (`windowName.ts` skips the bare `*` lookup). Script fix plus data regeneration.
- ⬜ **#7 medium**: a drag that is not Tab Manager's (a link, image or text from a page) is accepted by windows and tabs and moves the current selection: `movedTabs` in `TabManager.tsx:2748-2753` falls back to `this.draggingOpen ?? this.selectedTabs()` when the drop carries no payload. Accept only our own drag types (`isOpenTabDrag`/`isSavedTabDrag` in `src/popup/dragPayload.ts` already exist for the marker).
- ⬜ **#18 low**: no option handler catches a rejected `storage.local.set`; `store()` (`TabOptions.tsx:573-576`) and the bare `saveSetting` calls at `:879,899` show the new value while storage keeps the old.
- ⬜ **#26 low**: when the notice that holds focus unmounts, focus falls to `document.body` and the keyboard handler on `#root` stops seeing keys; `Notice.tsx:39-42` only releases the hold. Call `focusRoot()` (`TabManager.tsx:1583`).

Left as they are, by decision, unless seen in use:

- 🚫 **#1**: the debug export strips only `user:password@`; query strings and fragments stay (the file is for bug reports, not for import; a query-stripping version was tried and reverted in `9c6178c`).
- 🚫 **#10**: dropping a pinned tab among unpinned ones shows "moves" but the browser clamps it (`dropReasons.ts`).
- 🚫 **#11**: every `xn--` label is decoded, including whole-script confusables Chrome keeps as punycode (`punycode.ts:4-5`).
- 🚫 **#19**: fixed frame parts take `--popup-width` in px; the premise (a viewport narrower than requested) has never been seen.

✅ Fixed before the merge (for the record): #4 Enter and Space on the three native buttons (`buttonKeys.ts` `nativeButtonKeyDown`), #5 prefix-only query selected every tab, #6 dragged tabs in click order (`openMovePlan.ts` `shownOrder`), #8 punycode RangeError, #9 negative match count, #12 bidi controls in names, #13 saved window without a date, #14 number settings stored as text, #15 popup size clamp, #16 `importSessions` without `reader.onerror`, #17 visibilitychange flush in own-tab mode, #20 prefers-reduced-motion (`css/motion.css:203`), #21 text contrast 4.5:1, #22 `key.pem` not ignored, #23 AMO text on monitors, #24 debug export round trip overwrote saved windows (regression of the #1 attempt, gone with the revert), #25 created date fell back to now, #27 ZWJ stripped from names, #28 `.mcp.json` not ignored.
