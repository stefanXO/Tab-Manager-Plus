Tab Manager Plus
===============

The Marie Kondo for your Chrome Tabs! Do all these open tabs bring you joy? Let's organize them ^_^

The best tool to find, close, or switch to the tabs you want, when you have many tabs and windows. In a world of ever-expanding tabs in the browser - this is a helpful addition to keeping them organized and for quick switching between them!

If you like it, please leave a review! We read all the reviews ❤

★  What is Tab Manager Plus?

A simple and super-fast Google Extension to help you get the best overview over many tabs.  It helps filtering your tabs, moving them, re-arranging them.  Once you open Tab Manager Plus, you can type right away.  The main focus in this app is speed - so you can find the tab you're looking for - right away!

★  Functionality:

➤ Display all Tabs & Windows quickly in current window
➤ Highlight duplicate tabs - only the extra copies are selected, the one you used last is kept
➤ Highlight the tabs you used recently
➤ Select Tabs using Right Click, Ctrl, Cmd or Shift
➤ Quickly filter tabs by title and url ( just type - right away! )
  ➤ Switch to found tab with "Enter"
  ➤ Move multiple highlighted tabs with "Enter"
  ➤ Search in titles with t:word, in urls with u:word, leave tabs out with -word, search "a phrase" or a /regular expression/
  ➤ s:word searches saved windows only, -s:word open tabs only, also s:u:word, s:t:word
➤ Switch to your previously active tab with Alt+Shift+Comma (PC) / Ctrl+Shift+Comma (Mac)
➤ Limit open tabs - Tab Manager will open a new tab in a new window once your limit is reached
➤ Create new Tabs & Windows
➤ Move Tabs between Windows
➤ Delete Tabs & Windows, saved ones too - close the selection with Ctrl+Delete (Cmd+Delete on a Mac), undo a saved delete with Ctrl+Z
➤ Pin/unpin Tabs
➤ Discard tabs to save memory
➤ See which tabs play sound, are muted, asleep or pinned
➤ Windows are named after their sites automatically (GitHub, Gmail, Google Docs)
➤ Name and color your windows - names and colors survive a browser restart
➤ Save windows and restore them later, with their size and position (on by default); save the selected tabs as a new saved window
➤ Rename and recolor a saved window by clicking its name; export and import saved windows
➤ Drag saved tabs into open or other saved windows, open tabs into saved windows, and reorder them
➤ "Enter" opens selected saved tabs in a new window
➤ Hold the mouse on a tab or window for details: last used, tab counts, sites, monitor, and where a saved window will restore
➤ Light and dark theme, or follow your system
➤ Supports incognito mode, if you enable it

Tab Manager Plus is open source.

The main purpose of Tab Manager Plus is to find "lost" tabs easily. You can open the Tab Manager with a keyboard shortcut - Alt+Shift+M (PC) / Ctrl+Shift+M (Mac) or by clicking on the icon - and then you can type right away!

The Tab Manager will then show you all tabs that match your search terms - by tab title, and by url. If you've found your tab, and it's the only one selected - press "enter" - and you will jump right to it!

If you don't like one of the layouts, there are 4 views available in total :

★ Block view ( Shows you groups of icons - each window is one group )
★ Big block view ( same as above, but with bigger icons )
★ Rows view ( every window is one line, and every tab is represented by an icon )
★ List view ( a list of all your tabs - with readable titles )

You can move tabs between windows in every view - and you can select tabs with your right mouse button ( or CTRL+click on Mac ). Once you have selected a few tabs, simply press the "enter" key, and all tabs will be moved to a new browser window.

Are you stuck with lost duplicate tabs? Simply press the "duplicate tabs" icon, and Tab Manager will select the extra copies for you and keep the one you used last. Ctrl+Delete (Cmd+Delete on a Mac) or the trash button closes just the duplicates, "Enter" moves them to a separate window.

➤ Don't like animations? You can turn off / turn on animations in the options.

➤ The window is too big - the tabs take too much space? Switch to a compact view in the options - it's less beautiful, but more space efficient.

➤ Each window has action buttons: the star saves it for later, + opens a new tab in it, the pen names and colors it, the arrow minimizes it and x closes the whole window. Don't need them? Turn off "Show action buttons" in the options.

If you want to have an overview over your incognito tabs as well - make sure to go into the extension settings, and to enable the extension in Incognito mode.

★ Additional benefits

Depending on how many scripts are running inside your tabs, cleaning out duplicates from time to time can also speed up your computer by reducing the CPU load. Please take care of your computer.
