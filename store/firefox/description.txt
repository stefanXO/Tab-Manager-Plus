★  What is Tab Manager Plus?

Tab Manager Plus is a simple and fast Firefox add-on that gives you a clear view of all your open tabs.
You can filter them, move them between windows and organize them in whatever order you like.
Open Tab Manager Plus and start typing right away. Speed is our main priority, so that you can locate the tab you need almost immediately.

★  What you can do:

➤ See all of your tabs and windows together in one overview, instead of clicking through every window separately.
➤ Highlight duplicate tabs. Only the extra copies are selected, and the copy you used last is kept.
➤ Highlight the tabs you used most recently, so you can return to your current activity quickly.
➤ Select several tabs with a right click, or by holding Ctrl, Cmd or Shift while clicking.
➤ Filter your tabs by their title and web address simply by starting to type.
  ➤ Press "Enter" to switch immediately to the tab you found.
  ➤ Press "Enter" to move all highlighted tabs into a new window.
  ➤ Search only titles with t:word, and only web addresses with u:word.
  ➤ Exclude unwanted tabs from the search results by typing -word.
  ➤ Search for an exact phrase by typing "a phrase" inside quotation marks.
  ➤ Search with a /regular expression/ when you need a precise pattern.
  ➤ Search exclusively inside your saved windows by typing s:word.
➤ Switch back to your previous tab with Alt+Shift+Comma (PC) or Ctrl+Shift+Comma (Mac).
➤ Open Tab Manager Plus with Alt+Shift+M (PC) or Ctrl+Shift+M (Mac).
➤ Limit the number of tabs allowed in each window. Once a window reaches its limit, new tabs automatically open in a new window.
➤ Create new tabs and windows directly from the overview.
➤ Move tabs between windows by dragging them to the exact position you want.
➤ Close tabs and whole windows, including saved ones.
➤ Undo deleting a saved window or saved tab with Ctrl+Z (Cmd+Z on a Mac).
➤ Pin and unpin tabs, so important pages stay at the beginning of the window.
➤ Put tabs to sleep so that they use less memory while you are not using them.
➤ See at a glance which tabs are playing audio, muted, sleeping or pinned.
➤ Windows are named automatically after their sites, like GitHub or Gmail, so they are easy to tell apart.
➤ Name and color your windows yourself, and the names and colors remain after Firefox restarts.
➤ Save windows and open them again later, with their original size and position.
➤ Rename and recolor saved windows, and export or import them as a backup.
➤ Drag tabs into saved windows, and move them between saved windows.
➤ Hold the mouse over a tab or window to see more details about it.
➤ Choose a light theme or a dark theme, or let it follow your operating system automatically.
➤ Use it in the Firefox sidebar, in the popup, or in a tab of its own.
➤ Minimize inactive windows: one window stays active, and all the others are minimized.
➤ It works in private windows if you allow it, and the options show you how to do that.
➤ When you save a window, its about:blank tabs are included as well.
➤ "Change shortcut key" in the options opens the Firefox shortcut settings, so you can pick your own keys.
➤ It also works in browsers built on Firefox, like LibreWolf, Zen and Waterfox.

Tab Manager Plus is open source, so anyone can read and verify its code.

The main purpose of Tab Manager Plus is to help you rediscover tabs you have lost. Open it with Alt+Shift+M (PC) or Ctrl+Shift+M (Mac), or click its icon, and then start typing right away.

It immediately shows every tab whose title or web address matches the words you entered.
When the tab you were looking for is the only one selected, press "Enter" to jump directly to it.

There are 4 layouts:

★ Block view ( one group of icons for each window )
★ Big block view ( the same, with bigger icons )
★ Rows view ( one line for each window, one icon for each tab )
★ List view ( a list of all your tabs, with readable titles )

You can move tabs between windows in every layout.
Select individual tabs with the right mouse button, or with Ctrl+click on a Mac.
Then press "Enter" to move all of the selected tabs into a new window.

Stuck with duplicate tabs? Press the "duplicate tabs" icon, and Tab Manager Plus selects the extra copies while keeping the one you used last. Then Ctrl+Delete (Cmd+Delete on a Mac) closes just the duplicates, or "Enter" moves them into a separate window.

➤ If you find the animations distracting, you can turn them off in the options.

➤ If the window is too big for your screen, you can switch to a more compact view in the options.

➤ Each window has its own row of buttons with different functions. The star saves it, the + opens a new tab in it, and the pen lets you name and color it. The arrow minimizes the window, and the x closes the whole window. If you don't need these buttons, you can easily turn them off in the options.

To see your private tabs as well, allow the add-on in private windows; the options explain exactly how to do it.

★ Good to know

Duplicate tabs that run scripts can slow down your computer, so it is a good idea to close them from time to time. Please take good care of your computer.
